# Mehul Purohit — website

Static site built with Vite (`npm run dev`, `npm run build`).

- `index.html`, `style.css`, `script.js` — page, styles and interactions
- `public/awards/` — real award and event photos (ring, moments strip, giants list)
- `public/img/` — client logos, news logos and scene photography
- The hero portrait is the same hosted cut-out used on multiphasedigital.com
